# Surface: la guía (app/index.html)

Mode: Read (guide), with Operate controls (marcar pasos, calcular tamaño). Phone first: read on a phone while the PC installs.

Audience and job: anyone putting Ubuntu LTS next to Windows; follows step by step, marks progress, needs to know at each moment whether what they did is reversible and how to go back.

## Direction contract

THESIS: the install as a climbing route topo. Pitches (largos) are phases, belays (reuniones) are the safe places to stop, the point of no return is marked, and the descent line (undo) is drawn from the start. Refuses the category default: a docs page with sidebar, coloured callout boxes and a progress bar.

OWN-WORLD: four inks only: limestone ground (#ecede8), graphite (#17191c), rope orange (#e8461e), auxiliary grey (#7d8580); night version swaps ground to graphite rock. Archivo with its width axis: condensed caps for the topo apparatus (pitch labels, belays, running head), normal width for reading. State is line form, not hue: solid rope line = done, thin grey = pending, dashed = descent, doubled tick = no way back. Belays are numbered circles.

STORY: the reader understands the whole route before starting, believes nothing is irreversible without warning, and does each step marking it; when they come back the page puts them where they stopped.

FIRST VIEWPORT: header with running head (title, «Largo n de 8»), the title in condensed heavy caps, and the route in miniature: numbered belays joined by rope (done) or thin line (pending), with the «estás aquí» ring persisted. Below, the current pitch: label (largo, dónde, riesgo), heading, intro, checkable steps with «Deberías ver», closing belay note. The route line runs down the left margin.

FORM: candidate 5 of 7 (climbing route topo), seed:855dac69b34dd748. Raises: four inks only (quarterly), state as line form (emission rail), where you stopped persisted and re-flagged (cutting bench), the miniature route shows how many pitches remain (coptic).
